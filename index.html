操作說明 / How to use

建議使用 Microsoft Edge，可享有更多語音（發音）選擇。

1. 載入文章

在右側「Paste or load article」選擇文章或貼上/上傳 .txt，按 Load。文章會依空行分成多個 Section。

2. 聽打流程

  • 左側：◀▶ 換句，大按鈕 ▶ 播放目前句子，Speed 可調語速，「Play section」播放整段。
  • 上方 Voice 可選發音，中間框輸入你聽到的句子。
  • Check 對答案，Reveal Answer 直接看答案，Clear Input 清空輸入。

3. 鍵盤快速鍵（免滑鼠）

  • Alt+P 播放目前句
  • Ctrl+Enter 送出檢查
  • Alt+← 上一句　Alt+→ 下一句
  • 換句後再按 Alt+P 播放該句

4. History 與重練

右側 History 依 Section 顯示每段檢查紀錄與平均。低於門檻的會標「建議重練」；可點「重練此句」單句重練，或 Section 旁的「Re-practice low」只重練該段低分句。Export 可匯出 JSON 供 AI 分析弱點。

5. 其他

「Hide sentence」可隱藏答案區；「Show section」顯示整段原文。Strict mode 開啟時標點與大小寫須一致才算對。
